# Birdtray 1.14.0 — Ubuntu 26.04 Resolute

- Adds Thunderbird window controls for KDE Plasma Wayland via KWin.
- Retains X11 window controls and the unread-counter recovery from 1.13.0.
- Updates English and Spanish interface text, application metadata, and help links.
- Keeps the standard package name and configuration paths.

Community edition based on Birdtray 1.11.4. Original credits and GPLv3 are retained.
The KWin approach was inspired by stark1tty/birdtray-wayland.
